# Fractions

A fraction is written top/bottom: the top is the numerator, the bottom is the denominator.

To add fractions, first make the denominators the same.

Example: 1/2 + 1/3
Common denominator is 6, so 3/6 + 2/6 = 5/6.

Example: 1/4 + 1/4 = 2/8

To simplify a fraction, divide the top and bottom by the same number.
Example: 4/8 = 1/2
