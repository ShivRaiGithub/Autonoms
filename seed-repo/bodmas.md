# BODMAS (order of operations)

Do the parts of a sum in this order:

1. Brackets
2. Orders (powers and roots)
3. Division and Multiplication (left to right)
4. Addition and Subtraction (left to right)

Example 1: 2 + 3 x 4
Multiplication comes before addition, so 3 x 4 = 12, then 2 + 12 = 20.

Example 2: (2 + 3) x 4
Brackets first, so 5 x 4 = 20.
